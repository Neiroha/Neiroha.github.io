对话 TTS 适合游戏对话、广播剧台词、短视频脚本和多角色配音制作。

## 创建项目

进入 **对话 TTS（Dialog TTS）**，点击 **新建项目**，填写项目名称并选择语音库。

## 添加台词

在右侧面板底部输入栏中：

1. 从 **音色** 下拉菜单选择角色。
2. 输入台词文本。
3. 点击发送按钮。

每一行会以聊天气泡形式出现在项目中，便于按角色阅读和编辑。

## 生成与播放

- 点击 **全部生成** 会按顺序合成尚无音频的台词。
- 合成失败会在气泡上显示错误状态。
- 点击气泡上的播放按钮可以试听该行音频。
- 波形动画显示播放进度和已用 / 总时长。
