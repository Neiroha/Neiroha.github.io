对话 TTS 适合游戏对话、广播剧台词、短视频脚本和多角色配音制作。

<img className="screenshot" src="/img/screenshot_dialog_tts.png" alt="对话 TTS 页面" />

## 创建项目前

1. 至少有一个已启用 Provider。
2. 至少有一个 Quick Test 通过的语音角色。
3. 这些角色已经放进同一个语音库。

## 创建项目

1. 打开左侧导航的 **Dialog TTS**。
2. 点击 **新建项目**。
3. 填项目名称，例如 `第一章 对话`。
4. 选择语音库。
5. 进入项目编辑器。

## 添加台词

在右侧面板底部输入栏中：

1. 从 **音色** 下拉菜单选择角色。
2. 输入台词文本。
3. 点击发送按钮。

每一行会以聊天气泡形式出现在项目中，便于按角色阅读和编辑。

## 按行检查

每个气泡需确认三件事：

| 检查项 | 为什么 |
|---|---|
| 角色是否正确 | 后续生成会使用这一行绑定的角色 |
| 文本是否是最终稿 | 改文本后需要重新生成音频 |
| 是否已有音频 | 已有音频的行可以播放，缺失音频的行需要生成 |

## 生成与播放

1. 先生成单行，确认该角色可以正常合成。
2. 再点击 **全部生成**，批量合成尚无音频的台词。
3. 合成失败会在气泡上显示错误状态。
4. 点击气泡上的播放按钮可以试听该行音频。
5. 波形动画显示播放进度和已用 / 总时长。

所有行都会进入共享 TTS 队列，所以 Provider 的并发和限流会影响 Dialog TTS 的速度。使用云端免费层时宜先小批量生成。

## 多角色脚本建议

| 脚本形态 | 建议 |
|---|---|
| 已经有角色名前缀 | 逐行复制，手动选择对应角色 |
| 短视频对白 | 一行一个镜头或一个字幕 cue |
| 广播剧 | 先建完整角色库，再按角色筛查 |
| 同一角色多种情绪 | 创建多个角色变体，例如 `旁白-平静`、`旁白-紧张` |

## 失败处理

| 现象 | 处理 |
|---|---|
| 单行失败 | 打开错误信息，返回 Quick TTS 复现 |
| 批量中途失败 | 降低 Provider 并发，保留成功行，只重试失败行 |
| 改了文本但还播放旧音频 | 重新生成该行 |
| 角色下拉框缺少所需角色 | 返回 Voice Bank，把角色加入当前项目绑定的语音库 |

## 导出处理

生成完成后，可从项目输出目录收集音频文件。需要整段合并、分轨、静音间隔或字幕对齐时，可将导出的音频导入音频编辑器或视频剪辑软件继续处理。
