语音角色是 Neiroha 的核心抽象。每个角色绑定一个已启用 Provider、音色或模型、任务模式、语速，以及可选头像和参考音频。

## 创建语音角色

进入 **语音库（Voice Bank）**，选择或创建一个语音库，然后点击 **New Character**。

常用字段：

| 字段 | 说明 |
|---|---|
| 名称 | 在界面、项目和 API 请求中显示或匹配的角色名 |
| 提供商 | 一个已启用的 Provider |
| 任务模式 | 决定角色编辑器展示预设音色、参考音频或指令式音色字段 |
| 语速 | 合成速度倍率，通常为 0.5 到 2.0 |
| 头像 | 可选图片，在对话气泡中显示 |

## 任务模式

| 模式 | 适用后端 | 配置重点 |
|---|---|---|
| 预设音色 | OpenAI、Azure、Windows SAPI、Gemini 等 | 从 Provider 音色列表选择 voice |
| 音色克隆（带提示） | GPT-SoVITS、CosyVoice、VoxCPM2 等 | 提供参考音频和对应文本 |
| 音色设计 | 支持 `voice_instruction` 或 Chat Completions 音频输出的模型 | 用自由文本描述声音风格 |

## 构建语音库

语音库用于按项目、语言、角色集合或制作任务分组管理角色。

1. 在 **Voice Bank** 点击 **+ 新建库**。
2. 填写名称。
3. 在当前库中创建角色，或从其他库导入已有角色。
4. 点击目标库上的 **设为激活**。

激活的语音库会作为新项目和 API 音色 / 模型列表的默认作用域。

## API 中的模型概念

本地 API Server 把语音库抽象成 OpenAI 风格的 `model`：

- `/v1/models` 返回已激活的语音库。
- `/v1/audio/voices` 返回激活语音库中的角色。
- `POST /v1/audio/speech` 可以通过 `model` 将 `voice` 查找限定到某个语音库。
