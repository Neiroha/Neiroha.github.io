段落 TTS 面向长篇叙事、有声书和需要逐段处理的脚本。

<img className="screenshot" src="/img/screenshot_phase_tts.png" alt="段落 TTS 页面" />

## 适合什么文本

| 文本 | 适合度 |
|---|---|
| 旁白稿 | 适合，按空行或段落拆分 |
| 有少量对话的小说章节 | 适合，拆段后手动分配角色 |
| 大量多角色对白 | 优先用 Dialog TTS，并在导入前整理说话人标记 |
| 超长整本书 | 按章节拆分文件后逐章导入 |

## 基础流程

1. 创建项目。
2. 选择语音库。
3. 将完整脚本粘贴到文本框中。
4. 使用 **拆分** 将脚本按空行或句子边界切成段落。
5. 审阅每个段落，修正过长、过短或标点异常的片段。
6. 为段落分配角色。
7. 先生成 1 到 3 个段落试听。
8. 点击 **全部生成** 批量合成。
9. 从状态栏显示的输出目录导出或复制音频。

## 拆分建议

| 问题 | 建议 |
|---|---|
| 一段太长 | 手动加空行，避免一次请求超出云端上下文或免费层 TPM |
| 一段太短 | 合并纯语气词或只有标点的片段 |
| 角色切换频繁 | 每句对白单独拆一段，方便分配 voice |
| 旁白和对白混在一起 | 拆成“旁白段”和“对白段”后再分配角色 |

## 批量前检查

| 检查项 | 原因 |
|---|---|
| Provider 并发 | 云端免费层应使用较低并发 |
| RPD / TPM | 避免长文本一次触发 429 |
| 角色分配 | 未分配 voice 的段落无法生成 |
| 输出目录 | 确认磁盘空间和存储路径 |

## 角色分配建议

长文本出现多个说话人时，先把文本拆成可读的短段，再手动把每段分配给语音库中的角色。

| 情况 | 处理方式 |
|---|---|
| 旁白占大多数 | 先把所有段落分给旁白，再调整对白段 |
| 角色名称写在台词前 | 保留角色名前缀作为人工校对线索，生成前再决定是否删除 |
| 同一角色情绪变化大 | 复制角色并调不同 voice instruction、语速或参考音频 |
| 批量很长 | 每次先生成少量段落，确认稳定后再继续 |

## 导出建议

- 分章节或分场景创建项目，便于后期整理。
- 生成完成后从界面显示的输出目录收集音频。
- 需要固定文件名时，先在项目内给段落编号，再按编号导出或整理。
