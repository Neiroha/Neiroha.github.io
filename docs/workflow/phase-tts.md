段落 TTS 面向长篇叙事、有声书和需要逐段处理的脚本。

## 适合什么文本

| 文本 | 适合度 |
|---|---|
| 旁白稿 | 很适合，按空行或段落拆分 |
| 有少量对话的小说章节 | 适合，拆段后手动分配角色 |
| 大量多角色对白 | 优先用 Dialog TTS，或等待角色识别流程完善 |
| 超长整本书 | 先按章节拆文件，再逐章导入 |

## 基础流程

1. 创建项目。
2. 选择语音库。
3. 将完整脚本粘贴到文本框中。
4. 使用 **拆分** 将脚本按空行或句子边界切成段落。
5. 审阅每个段落，修正过长、过短或标点异常的片段。
6. 为段落分配角色。
7. 先生成前 1 到 3 个段落试听。
8. 点击 **全部生成** 批量合成。
9. 从状态栏显示的输出目录导出或复制音频。

## 拆分建议

| 问题 | 建议 |
|---|---|
| 一段太长 | 手动加空行，避免一次请求超出云端上下文或免费层 TPM |
| 一段太短 | 合并纯语气词或只有标点的片段 |
| 角色切换频繁 | 每句对白单独拆一段，方便分配 voice |
| 旁白和对白混在一起 | 先拆成“旁白段”和“对白段”，再分角色 |

## 批量前检查

| 检查项 | 原因 |
|---|---|
| Provider 并发 | 云端免费层不要开太高 |
| RPD / TPM | 避免长文本一次触发 429 |
| 角色分配 | 没分配 voice 的段落无法生成 |
| 输出目录 | 确认磁盘空间和存储路径 |

## 角色分配方向

计划中的 LLM Role Assignment 会把长文本变成带说话人信息的 Phase TTS 片段：

- 从当前脚本运行角色识别。
- 展示片段文本、分类、说话人标签、置信度和建议音色。
- 在应用前允许用户覆盖说话人到语音角色的映射。
- 将映射写回 segment voice assignment。
