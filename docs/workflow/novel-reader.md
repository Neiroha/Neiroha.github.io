小说阅读器用于长篇 TXT 阅读和缓存式 TTS 播放。

## 适合什么场景

| 场景 | 建议 |
|---|---|
| 个人听书 | 使用小说阅读器，开启缓存和预取 |
| 制作正式有声书 | 用段落 TTS 更适合审稿和导出 |
| 多角色精修对白 | 用对话 TTS 或段落 TTS 分段处理 |

## 使用流程

1. 从 TXT 文件或文件夹创建小说项目。
2. 从项目绑定的语音库中选择旁白音色和对话音色。
3. 配置切片、跳过纯标点片段、预取数量、自动翻页和章节自动推进。
4. 点击播放。

播放时，阅读器会生成缺失音频、写入磁盘缓存，并通过共享 TTS 队列预取后续片段。

## 第一次配置建议

| 设置 | 建议值 |
|---|---|
| 最大切片字符 | `40` 到 `80`，按模型稳定性调整 |
| 跳过纯标点片段 | 开启 |
| 预取数量 | 云端免费层设 `1` 到 `2`，本地服务可逐步提高 |
| 自动翻页 | 需要连续听书时开启 |
| 自动推进章节 | 首次测试先关闭，确认缓存逻辑后再开启 |

## 连续播放

如果希望切到设置或任务页时小说继续朗读，保持：

```text
设置 → General → Keep TTS Running Across Screens
```

## 并发说明

提供商并发数会作用在小说阅读器的生成任务上，但实际并发还取决于阅读器预取数量。要充分利用提供商并发，请让预取数量不低于提供商并发数，并确认 RPM/TPM 等限流没有触发。

云端免费层不宜同时提高预取数量和提供商并发。小说阅读器会边读边补缓存，过高预取可能在短时间内消耗大量请求。

## 缓存路径

默认输出目录：

```text
%APPDATA%\com.neiroha.neiroha\voice_asset\novel_reader\
```

## 缓存状态

| 状态 | 含义 |
|---|---|
| 没有缓存 | 播放到该片段时需要现生成 |
| 当前缓存 | 文本和角色没有变化，可以直接播放 |
| 过期缓存 | 文本、角色或设置变了，需要重新生成 |

如果文本被重新切片，旧缓存可能无法对应新片段。正式长篇项目建议先确定切片策略，再大量生成。
