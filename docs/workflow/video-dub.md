视频配音模块面向“字幕 → TTS → 导出配音”的单视频工作流。它不是完整剪辑软件，但覆盖常见配音制作路径。

## 基础流程

1. 创建项目并选择语音库。
2. 导入视频到 V1，原视频音频会作为 A1 关联轨道。
3. 导入 SRT 或 LRC 字幕。
4. 为字幕 cue 生成 TTS。
5. 在轻量时间轴上移动字幕和导入音频。
6. 必要时使用同步长度工具，让生成语音贴合字幕时间窗。
7. 使用 **设置 → Media Tools** 中配置的 FFmpeg 默认值导出音频或配音视频。

## 平台限制

视频配音依赖本地 FFmpeg 能力：

| 能力 | Windows | Linux / macOS | Android |
|---|---|---|---|
| 外部 FFmpeg CLI 路径 / PATH 检测 | 支持 | 支持 | 禁用 |
| 本地波形提取、裁剪、混音导出 | 支持 | 支持 | 禁用 |

Android 端保留 UI 与 TTS 客户端工作流，但本地 FFmpeg 混流、裁剪、波形提取和视频导出不可用。

## 已知改进项

视频配音相关的活跃风险记录在 [Bugs And Risks](/bugs) 中，包括：

- 导出需要匹配预览中的 A1 覆盖 gating。
- 打开项目时需要扫描缺失视频、A1/A3 媒体和字幕生成音频。
- 时间线需要 cue overlap 警告。
- 编辑 cue 后需要更顺手的自动重新生成流程。
- A3 导入音频需要支持预览播放。
